# Embedded invoice fonts

These are unmodified Liberation Sans Regular and Bold TrueType font files,
distributed under SIL Open Font License 1.1. The full copyright and license
notice is in `FONT-LICENSE.txt`.

The `BivaroSans-*.ttf` filenames are application-owned file aliases; the font
programs and their internal font names are unchanged. The fonts are embedded
and subset into controlled own-invoice PDFs. They are not loaded from user
paths, user settings, the host operating system or a remote font service.

Upstream: <https://github.com/liberationfonts/liberation-fonts>

Source of these exact copies: the environment's installed `fonts-liberation`
package, `/usr/share/fonts/truetype/liberation/LiberationSans-{Regular,Bold}.ttf`.
