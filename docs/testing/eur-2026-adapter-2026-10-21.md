New agricultural reserve 27 and subtotal 28 are not added or inferred from ordinary goods.

A same-year `/handoff?year=YYYY` alternative and bounded preview API path are returned, without inventing official rows or silently using a prior year's mapping. The dialog also links the existing handoff workspace; it does not automatically fetch or download an alternative package.
